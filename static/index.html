Game design

Scene graph

Select a scene to assign its world map, player behavior and entry audio. Transitions run in their displayed order; the first matching trigger wins.

Scene inspector

Transitions

Timers count NES frames. Scene names support letters, digits, spaces and -_!?. Player preset uses a 16×16 hitbox; nonzero map tiles are solid.

Scene placement

Select a marker or choose an instance, then click the map to move it. Positions snap to 8 pixels; exact coordinates remain editable. Outlines show 16×16 hitboxes. Pickups count on contact; press A inside a door to enter. Pickups respawn when a room is entered. Patrols turn at walls and endpoints.

Reusable entities

A definition supplies art and behavior to all its instances. Remove its instances before removing the definition. Art is edited in Sprites. Patrol is a moving object; enemy combat is a later system.

Game variables

Variables hold 0–65535 and persist between rooms. Initial values are restored by GameFlowStart. Names start with a letter and use letters, digits or underscores. Custom code can use gv_Name. Each variable uses two RAM bytes.

Scene events

All conditions must match

Actions in order

Events run after scene transitions, movement and entity interactions. Matching events run in order; a scene change must be the final action and stops remaining events that update. Entry events run once on the next eligible update. Timer events default to once per visit; disable it to repeat after the threshold. Addition and subtraction clamp to 0–65535.

Controller scenarios


                        
Each run boots a fresh flow ROM for 10 frames, then holds the selected buttons for each step. Use a step with no buttons to release them. Assert a scene, X/Y position, pickup count, active entity count or game variables. Blank variable fields skip the assertion; 0 asserts zero. Total limit: 600 frames including boot. Your custom main.swiss is preserved.

                    

                    
Your custom main.swiss stays editable. Flow preview and smoke tests use a separate harness. Include game_flow.swiss and call GameFlowStart / GameFlowUpdate to use the graph from your own code. Art, maps, animations, music and effects are edited in their existing workspaces.
